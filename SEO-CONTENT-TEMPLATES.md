## ✅ SEO Checklist for Each Post

Before publishing, ensure:

- [ ] Title includes target keyword (first 60 chars)
- [ ] Meta description includes keyword + CTA (150-160 chars)
- [ ] URL slug is keyword-rich and concise
- [ ] H1 tag unique and includes keyword
- [ ] H2/H3 structure logical and scannable
- [ ] First paragraph includes keyword naturally
- [ ] Keyword density 1-2% (natural usage)
- [ ] 3+ internal links to relevant pages
- [ ] 2+ external links to authority sources
- [ ] Images optimized (<100KB) with alt text
- [ ] Article schema added
- [ ] FAQ schema added if applicable
- [ ] At least 1500 words (2000+ for pillar content)
- [ ] Conclusion includes clear CTA
- [ ] Mobile-friendly formatting
- [ ] Passes Grammarly/readability check
